# 본문 이미지 테두리 (img_boarder) 1.2.2

글쓰기 화면에서 본문 이미지의 테두리를 굵기·색상·모양·곡선·그림자·테두리 이미지로 지정하는 라이믹스 모듈입니다.

| 항목 | 내용 |
| --- | --- |
| 종류 | 라이믹스 모듈 (Rhymix 2.x) |
| 버전 | 1.2.2 (2026-11-22) |
| 설치 경로 | `/modules/img_boarder` |
| 자료실 | https://moonhouse.co.kr/xemy/622141 |
| 적용 예 | https://moonhouse.co.kr/pic/558005 |
| 저작자 | 80san (문하우스) |

> 저장소 이름의 `boarder`는 `border`의 오타입니다. 폴더 이름(`img_boarder`)이 설치 경로이므로 **이름을 바꾸지 말고 그대로** 올리세요.

## 주요 기능

| 항목 | 내용 |
| --- | --- |
| 테두리 굵기·색상 | 이미지 둘레에 선을 그립니다. |
| 테두리 모양 | 실선·점선 등 선 종류 |
| 모서리 곡선 | 둥근 모서리 반경 |
| 그림자 | 이미지 아래 그림자 |
| 테두리 이미지 | 선 대신 이미지를 올려 액자처럼 감쌉니다. |
| 최소 가로 크기 | 정한 폭보다 작은 이미지에는 테두리를 적용하지 않습니다. |
| 다수 이미지 선택 (1.2.2) | 한 글에서 테두리를 지정할 이미지를 여러 개 고를 수 있습니다. |
| 이미지별 테두리 (1.2.2) | 이미지마다 개별 테두리를 지정하고, 나머지는 기본 설정을 따릅니다. |

## 설치

1. 압축을 풀어 `img_boarder` 폴더를 `/modules/img_boarder` 에 업로드합니다.
2. 관리자 > 모듈 > 모듈 설치에서 **본문 이미지 테두리**를 설치합니다.
3. 관리자 > 본문 이미지 테두리 설정에서 **테두리를 적용할 게시판을 선택**합니다. (그 외 설정은 게시판마다 글에서 지정)
4. 테두리 이미지를 쓸 경우, 업로드를 허용할 회원그룹을 지정합니다.
5. 관리자 > 캐시파일 재생성.

## 사용법

1. 대상 게시판에서 글을 씁니다. 글 작성 화면 **하단에 옵션 영역**이 나타납니다. (폴딩 형식, 기본은 접힘)
2. 옵션을 펴서 굵기·색상·모양·곡선·그림자·테두리 이미지를 고릅니다.
3. 등록하면 본문 이미지에 테두리가 적용됩니다.

## 테두리 이미지 기능 (V1.1)

- 선 대신 이미지를 올려 테두리를 만들 수 있습니다. 기본 이미지 2개가 들어 있고 관리자는 삭제할 수 있습니다.
- 이미지는 **파일을 선택한 뒤 업로드해야** 정상 등록됩니다. (선택한 회원그룹만 업로드 가능)
- 등록된 테두리 이미지에 마우스를 올리면 큰 이미지로 팝업됩니다.
- 모서리 크기와 채우기 방식은 작성자가 고릅니다.

## 주의 사항

- 적용할 게시판을 관리자 설정에서 골라야 동작합니다. 게시판을 새로 만들면 설정에서 다시 선택하세요.
- **최소 가로 크기**보다 작은 이미지에는 테두리가 적용되지 않습니다. 작은 아이콘까지 테두리를 두르고 싶으면 이 값을 0에 가깝게 낮추세요.
- 테두리 이미지는 업로드 권한을 가진 회원그룹만 올릴 수 있습니다. 일반 회원에게 테두리 이미지를 고르게 하려면 선·색상 기능만 쓰세요.
- 테두리는 본문 출력 시 이미지에 입혀집니다. 본문 HTML을 직접 고친 글에는 적용되지 않습니다.
